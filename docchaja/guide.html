닥차자 (DocChaJa) 2.0 베타

HWP·HWPX·PDF·Office 문서의 파일 안 내용을 검색하는 Windows 프로그램입니다.

  • 공식 홈페이지
  • 설치 파일·변경 내역
  • 오류 신고·문의

이 안내는 2026년 10월 24일 공개하는 2.0 베타용입니다. 기존 UI와 CPU 검색을 사용하며, GPU 가속과 새 UI는 포함하지 않습니다.

설치와 제거

설치

  1. 공식 홈페이지에서 Windows용 2.0 베타 다운로드를 선택합니다.
  2. DocChaJa-Setup-2.0.0-beta-x64.exe를 실행합니다.
  3. 사용 조건과 설치 안내를 읽고 설치합니다. 바탕화면 바로가기는 선택 사항입니다.
  4. Windows 시작 메뉴에서 닥차자 (DocChaJa)를 실행합니다.

Python이나 개발 도구를 따로 설치할 필요가 없습니다. 현재 사용자 계정에 설치되며 기본 설치 폴더는 %LOCALAPPDATA%\Programs\DocChaJa입니다.

  • Windows 10/11 64비트용입니다. Windows 11 ARM에서는 x64 호환 실행을 사용합니다.
  • 키워드 검색은 AI 모델 없이 사용할 수 있습니다.
  • 의미 검색은 별도로 가져온 모델이 필요하며 CPU에서 처리합니다.
  • 원본 문서를 검색하는 데 한/글이나 MS Office는 필요하지 않습니다. 결과를 더블클릭해 원본을 열려면 해당 형식을 열 수 있는 프로그램이 필요합니다.
  • 메모리는 키워드 검색 4GB 이상, 의미 검색 8GB 이상을 권장합니다. 필요한 저장 공간은 문서량과 색인 크기에 따라 늘어납니다. 모델 파일은 약 330MB가 추가됩니다.

현재 설치 파일은 코드 서명이 없습니다. Windows에서 게시자 확인 또는 SmartScreen 안내가 나타날 수 있습니다. 공식 다운로드 경로와 릴리즈의 SHA-256을 확인하고, 조직에서 관리하는 PC라면 해당 설치 정책을 따르세요.

재설치·제거와 데이터

설치·제거 전 파일 → 종료로 앱을 완전히 종료하세요. 창을 닫아 트레이에 숨긴 상태는 종료된 상태가 아닙니다.

  • 같은 위치에 재설치하면 프로그램 파일을 교체합니다.
  • 제거: Windows 설정 → 앱 → 설치된 앱 → 닥차자 (DocChaJa) → 제거.
  • 원본 문서, 설정, 색인, 사용자가 가져온 모델은 제거하지 않습니다.
  • 기본 데이터 위치는 %USERPROFILE%\docchaja이며, 따로 지정한 저장 위치는 그대로 사용합니다.

처음 검색하기

  1. 왼쪽 인덱싱 관리 패널에서 폴더 추가를 누릅니다.
  2. 검색할 문서가 있는 폴더를 선택합니다.
  3. 인덱싱 시작을 눌러 문서를 검색할 수 있게 준비합니다.
  4. 키워드 색인이 준비되면 오른쪽 검색창에 검색어를 입력하고 검색 또는 Enter를 누릅니다.
  5. 결과의 문서 이름을 확인하고 더블클릭해 원본을 엽니다.

인덱싱은 문서를 미리 읽어 검색용 색인을 만드는 과정입니다. 처음 준비하는 시간은 문서 수·크기·PC 성능에 따라 달라집니다. 의미 검색 모델이 있으면 키워드 색인 뒤에 의미 검색용 데이터도 생성합니다. 키워드 검색 준비가 끝나면 의미 색인 완료를 기다리지 않고 키워드 검색을 사용할 수 있습니다.

왼쪽 패널이 보이지 않으면 검색창 옆 패널 전환 버튼이나 F9를 누르세요. 이 버전에는 새 UI의 패널 이동·자동 숨김 기능이 없습니다.

지원 문서와 검색 방식

문서 확장자 참고
한글 HWP, HWPX 내장 추출기로 본문 검색
PDF PDF 텍스트가 있는 문서 대상. 이미지 전용 스캔본의 OCR은 제공하지 않음
Word DOCX 구형 DOC는 지원하지 않음
PowerPoint PPTX 슬라이드 텍스트 검색
Excel XLSX 워크시트 내용 검색

손상되거나 암호·DRM으로 보호된 문서, 추출 가능한 본문이 없는 문서는 처리하지 못할 수 있습니다. 인덱싱 완료 요약과 로그에서 건너뛴 이유를 확인하세요.

키워드 검색

정확한 단어·용어를 찾을 때 사용합니다.

  • 단어: 계약서
  • 여러 단어: 계약서 검토 — AND 검색은 두 단어가 모두 있는 문서를 찾습니다.
  • OR 검색을 선택하면 입력한 단어 중 하나라도 있는 문서를 찾습니다.
  • 구문: "사업계획서 작성"처럼 따옴표를 사용합니다.
  • 검색 대상 체크박스로 파일 형식을 제한할 수 있습니다.

의미 검색

별도 모델을 가져온 뒤 의미를 선택합니다. 개인정보를 안전하게 보관하는 방법처럼 문장이나 구절로 질문하면 뜻이 가까운 문서를 찾습니다. 결과는 유사도와 표시 기준에 따라 달라지므로, 정확한 용어나 짧은 단어는 키워드 검색도 함께 사용하세요.

의미 검색은 관련 문서를 찾는 기능입니다. 문서를 읽고 답변을 생성하는 챗봇 기능은 제공하지 않습니다.

유사 문서·결과 활용

  • 도구 → 유사 자료 검색 — 파일 선택 (Ctrl+L): 기준 파일과 같거나 비슷한 문서를 찾습니다. 기준 파일 자체는 제외하고 다른 위치의 복사본은 표시합니다.
  • 도구 → 유사 자료 검색 — 폴더 선택 (Ctrl+Shift+L): 폴더 내 자료를 대상으로 유사 자료를 찾습니다.
  • Excel로 내보내기: 검색 결과를 Excel 파일로 저장합니다.
  • 결과의 우클릭 메뉴에서 파일이 있는 폴더를 열 수 있습니다.
  • 도구 → 추출 텍스트 뷰어: 저장된 추출 텍스트와 처리 상태를 확인하고, 필요한 텍스트를 내보낼 수 있습니다.

의미 검색 모델 가져오기

모델은 설치 프로그램에 포함하지 않습니다. 키워드 검색만 사용한다면 이 절차를 건너뛰어도 됩니다. 2.0 베타는 모델을 자동 다운로드하지 않으며, 외부에서 받은 파일을 가져오는 방식입니다.

모델: EmbeddingGemma 300M의 ONNX 변환본

  • 모델 파일 제공 페이지
  • Gemma 이용약관

모델 제공처의 이용 조건과 접근 절차를 확인하세요. 문서 검색·임베딩 계산은 로컬 PC에서 수행합니다.

필요한 파일 6개

제공 페이지의 경로 가져올 폴더에 둘 파일명
onnx/model_quantized.onnx model_quantized.onnx
onnx/model_quantized.onnx_data model_quantized.onnx_data
tokenizer.json tokenizer.json
tokenizer_config.json tokenizer_config.json
special_tokens_map.json special_tokens_map.json
config.json config.json
  1. 인터넷이 되는 환경에서 위 6개 파일을 받습니다.
  2. 6개를 모두 같은 폴더에 모읍니다. .onnx와 .onnx_data는 반드시 함께 있어야 합니다.
  3. 필요하면 USB나 공유 폴더로 사용할 PC에 옮깁니다.
  4. 설정 → AI 모델 관리 → 로컬 파일에서 가져오기에서 그 폴더를 선택합니다.
  5. 모델 등록 후 대상 문서의 의미 색인을 준비하고 의미 검색을 사용합니다.

파일 누락·JSON 오류·파일 크기 경고가 나타나면 다운로드가 끝났는지와 파일 이름을 확인하세요. 모델 페이지 HTML을 파일 대신 저장하지 않았는지도 확인하세요.

폴더와 인덱싱 설정

  • 폴더 추가 / 폴더 삭제: 검색 대상 폴더를 관리합니다. 목록에서 폴더를 빼는 작업은 원본 폴더 삭제가 아닙니다.
  • 문서가 추가·변경되면 다시 인덱싱하거나 설정 → 인덱싱 설정에서 자동 인덱싱을 켭니다.
  • 기본 파일 크기 제한은 200MB입니다. 큰 문서가 건너뛰어지면 제한을 확인하세요.
  • 심볼릭 링크·정션, 바로가기 따라가기와 네트워크 경로 포함 여부를 조절할 수 있습니다.
  • 자동 인덱싱 주기와 CPU·메모리 사용 설정으로 다른 작업과의 부하를 조절할 수 있습니다.
  • 실행 중 중단을 누른 뒤 다시 인덱싱하면 이미 준비된 데이터는 재사용할 수 있습니다.

검색 설정

설정 → 검색 설정에서 의미 검색 결과의 표시 기준과 모델 메모리 해제 시간을 조절합니다.

  • 결과 표시 기준은 자동 측정을 우선 사용하세요. 너무 적게 나오면 기준을 낮추고, 무관한 결과가 많으면 높여 보세요.
  • 자동 기준 측정에는 모델과 충분한 의미 색인 데이터가 필요합니다. 데이터가 적으면 아직 측정되지 않은 것으로 표시될 수 있습니다.
  • 일정 시간 사용하지 않은 모델을 메모리에서 해제할 수 있습니다. 다시 사용할 때 로딩 시간이 추가됩니다.
  • 2.0 베타에는 GPU 사용 옵션이 없습니다. GPU 가속과 새 UI는 별도의 3.0 개발 범위입니다.

문제 해결

검색 결과가 없어요

폴더 등록·키워드 색인 완료 여부와 검색 대상 파일 형식을 확인하세요. 의미 검색은 모델 등록과 의미 색인이 필요합니다. 짧은 단어라면 키워드 검색으로도 확인하세요.

HWP 또는 PDF가 건너뛰어져요

암호·DRM, 파일 손상, 이미지 전용 PDF, 크기 제한 여부를 확인하세요. 이전 추출 실패가 캐시에 남아 있다면 전체 재인덱싱에서 변경되지 않은 파일은 캐시 재사용을 끄고 다시 추출할 수 있습니다.

인덱싱이 오래 걸려요

첫 인덱싱과 의미 검색용 임베딩 생성은 시간이 걸릴 수 있습니다. 우선 작은 폴더부터 시작하고, 키워드 검색 준비가 끝나면 먼저 검색해 보세요. 의미 검색용 계산은 CPU를 사용합니다.

창을 닫았는데 설치·제거가 안 돼요

트레이 최소화 설정 때문에 앱이 남아 있을 수 있습니다. 앱을 다시 열고 파일 → 종료로 완전히 종료한 뒤 시도하세요.

이전 버전의 색인을 다시 만들라고 해요

1.x에서 2.0으로 넘어오면 색인 구조와 의미 검색 데이터가 달라 재인덱싱이 필요할 수 있습니다. 안내에서 진행 또는 기존 버전 유지를 선택할 수 있습니다. 중요한 설정과 데이터는 업그레이드 전에 별도 보관하세요.

오류를 신고하려면?

공개 오류 신고 페이지에 Windows 버전, 앱 버전, 재현 순서, 오류 메시지를 적어 주세요. 로그는 기본 데이터 폴더의 DocChaJa.log에 있습니다. 공개 게시 전에 문서 본문·파일 경로·개인정보를 지워 주세요.
